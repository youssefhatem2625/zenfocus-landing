# 🌿 ZenFocus — Minimalist Focus & Productivity Landing Page

صفحة هبوط تسويقية عصرية وهادئة مصممة ومبرمجة بـ **React.js** و **Tailwind CSS**، تتميز بكود نظيف ومعايير معمارية منظمة (Clean Code & Modular Architecture).

---

## 🚀 المميزات الرئيسية (Key Features)

- **تصميم هادئ ومريح للعين (Minimalist Aesthetic):** استخدام درجات ألوان ناعمة ومساحات بيضاء مدروسة بدون أي تشتيت بصري.
- **عنصر تفاعلي حي (Interactive Live Widget):** 
  - مؤقت تركيز بومودورو (25د تركيز / 5د استراحة) مع أزرار تشغيل وإيقاف وإعادة تعيين.
  - قائمة مهام تفاعلية تدعم الإنجاز والشطب الفوري.
  - محاكي لأصوات الطبيعة الهادئة.
- **كود نظيف ومنظم (Clean Code Architecture):**
  - فصل البيانات والنصوص بالكامل في ملف `src/data/content.js`.
  - مكونات واجهة ذرية قابلة لإعادة الاستخدام (`Button`, `Badge`, `Card`).
  - تقسيم أقسام الصفحة إلى مكونات مستقلة في مجلد `src/components/sections/`.
- **متجاوب 100% (Fully Responsive):** مضبوط بدقة على جميع شاشات الموبايل والتابلت والكمبيوتر.
- **خط عربي أنيق:** استخدام خط Cairo الحديث لضمان تجربة قراءة مريحة واحترافية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 18 / Vite:** أداء فائق وسرعة تحميل استثنائية.
- **Tailwind CSS v4:** تنسيق وتصميم عصري ونظيف.
- **Lucide React:** حزمة أيقونات خفيفة ومتناسقة.

---

## 💻 طريقة التشغيل محلياً (Run Locally)

1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. تشغيل سيرفر التطوير:
   ```bash
   npm run dev
   ```
3. فتح الرابط في المتصفح: `http://localhost:5173`
